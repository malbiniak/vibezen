# /resume

Session start runs at full tank — judgment belongs here (Brief 001).

1. If `AUDIT.md` exists and has entries, read the most recent dated entry **first**. Triage it with the operator before any new work: **fix now** (correctness, drift from SPEC.md, scope violations — these compound across sessions), **backlog** (→ SCOPE.md Later), or already-routed speculation. If the entry says "No material gaps," say so in one line and move on.
2. Read `SPEC.md`, `SCOPE.md`, and `STATUS.md`.
3. Report where things stand in plain English — including anything half-done if the last session ended early. Propose today's goal from SCOPE.md's Now list and STATUS.md's drafted next-session proposal. Wait for the operator to approve or redirect.

If the project's `CLAUDE.md` says its working docs live somewhere other than the repo root, read them there.
