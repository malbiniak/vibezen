# The Dogfood Folder

This repo runs the playbook it ships (see `SPEC.md`: "I want this repo to run the same rituals it prescribes"). Everything in this folder is that self-application — the repo's **own** working docs, not the product you adopt (Brief 004, Decision 5):

| File | What it is |
|---|---|
| `SPEC.md` | What this repo is and who it serves. |
| `SCOPE.md` | Its Now / Next / Later list. |
| `STATUS.md` | Where its own work stands. |
| `JOURNAL.md` | Append-only process memory of its sessions. |
| `AUDIT.md` | Wrap-up self-audits, triaged at each `/resume`. |
| `briefs/` | The decision-brief archive — the paper trail behind every change to the playbook. Filed unmodified, never edited after filing. |

To adopt the playbook, ignore this folder and follow the repo README: install the plugin, run `/new-project`.
